Welcome to My OS!
This is a simple x86 operating system.
Now written in modular C!

Features so far:
  - Protected mode kernel at 1 MB
  - Physical memory manager (bitmap)
  - Paging with identity mapping
  - Kernel heap (kmalloc/kfree)
  - 640x480 32bpp framebuffer
  - Bitmap font rendering
  - PS/2 mouse driver
  - ATA disk driver
  - MyFS filesystem
  - File manager UI
